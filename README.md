# damir657.github.io

Personal site of Damir Ashinov (Industrial Engineering & Operations Analytics, University of Arkansas).
Live at https://damir657.github.io/

- `index.html` – homepage with the campus traffic demo (`traffic.js`, `site.css`)
- `hillpark.html`, `permit-model.html` – project pages
- `data/` – demo data built by `tools/build_data.py` from the INEG 26103 project's TomTom log and campus map
  (rerun it to refresh the traffic map; it reads the TomTom key from that project's `.env`, never from this repo)

Map data © OpenStreetMap contributors. Traffic speeds from the TomTom Traffic API. Counts from ArDOT.
